Enterprise Software Management
================================
Files:
  index.html  - page structure (header, dashboard, table, Add/Edit form)
  style.css   - styling, light/dark theme variables
  script.js   - application logic (add, edit, delete, search, filter, sort, dashboard)

How to run:
  Keep the three files in the same folder and open index.html in any modern browser.

Data is stored in the browser (localStorage). Sample data loads on first run.
